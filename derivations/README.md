# Mathematical supplement

These are the original project working derivations, organized by question. The main paper provides a common notation and adjudicates the competing approaches. The dated notes preserve the assumptions and narrower input classes used in each argument. Historical file and run references in those notes refer to the development workspace. The [release checks](../checks/) and [recorded outputs](../evidence/) run independently of that workspace.

| Topic | Derivations | What the result gives |
|---|---|---|
| Conditional constant and arithmetic | [Short inverse hash](short_hash_count/count.tex), [chord elimination](c38_arithmetic_join/join.tex), [earlier composition](hillclimb_001/proof.tex) | The short operand reduces the leading graph cost. A free offset converts an ordinary target count to one guarded integer count under a stated rounding condition. |
| Feasible modes and exact local graphs | [Mode enumeration and graph checks](hillclimb_002/audit.tex), [factored packets](hillclimb_003/compression.tex), [closure under merging](hillclimb_005/closure.tex) | Candidate-enumeration costs and finite graph tests. The scope of each rank or compression claim depends on the chosen representation. |
| Precision and span | [Nonuniform grid](hillclimb_006/grid_audit.tex), [balanced clusters](hillclimb_007/cluster_bounds.tex), [degree-aware Hermite readout](hillclimb_008/readout.tex), [packet spaces and parity](hillclimb_009/space_and_parity.tex), [generic span theorem](generic_packet_span/span.tex) | Finite precision savings, their costs, and an all-width spanning theorem for complete generic binary packets. |
| Repeated slots and digits | [Effective arity](slot_arity/rate.tex), [second digit](second_digit/digit.tex) | Frobenius reductions and a common-step endpoint formula, with support and probability limits on independent windows. |
