# Mathematical supplement

These are the original project working derivations, organized by question. The main paper provides a common notation and adjudicates the competing approaches. The dated notes preserve the assumptions and narrower input classes used in each argument. Historical file and run references in those notes refer to the development workspace. The [release checks](../checks/) and [recorded outputs](../evidence/) run independently of that workspace.
