# How many wrong signed addresses pass a chord test?

**21 November 2026.** At the thinned mixed-slot widths, one fixed translation of the signed leaves gives a chord test with one-sided completeness. For every eligible fixed target, the true witness always passes, and the conditional expected number of wrong signed addresses on guarded singleton seeds is at most $(1+o(1))/(2m^2)$. Here $m$ is the growing number of slots. The expectation is over the original hash seeds. The result applies to smooth prime-field curves in the stated sampling regime. The direct implementation still transmits $m-2$ full-size internal abscissas. Its cost does not improve the general-prime exponent. [Proof and exact cost scope](target.md)

## The test

Choose a public point $R$ such that $T+[2j]R\ne\pm T$ for $1\le j\le m$. When the target has order greater than $2m+2$, take $R=T$. Translate each proposed signed point $P_i$ to $P_i+R$. Retain only its abscissa, with a symbol for infinity. A binary vertex with children $x(U),x(V)$ permits the parent $x(U+V)$ or $x(U-V)$. Ask if the root can be $x(T+[m]R)$.

The positive sign at every leaf keeps the true address. A choice of $j$ negative signs corresponds to a different target $T+[2j]R$ after reversing those signs in the original slots. A bound on the joint counts at two fixed targets pays for all $2^m-1$ extra sign patterns. This also bounds the expected number of surplus internal assignments, so a large number of certificates for one incorrect address cannot invalidate the estimate. On 60,026 guarded singleton patterns at $p=257$ the mean numbers of wrong addresses and surplus internal assignments were **0.145504** and **0.153900**. [Finite comparison](../../evidence/check_candidate_targets.txt)

At the project's arity, $m+2$ precomputed rational offsets give a stronger address test. If the **same** tuple passes all probes, its signed sum must equal the target. This holds simultaneously for all tuples, seeds and targets once the offsets have been checked. Separate existential queries could choose different addresses. A graph testing all offsets directly uses more field labels than the single-probe filter. [Universal offsets](universal.md) · [Checks](../../evidence/check_candidate_offsets.txt)

The single-probe guarantee is already strong enough for extraction **if pinned feasibility can be computed cheaply**. With $F$ wrong addresses and $\mathbb E[F\mid U]\le\epsilon$, the conditional probability of $F=0$ is at least $1-\epsilon$. On these singleton seeds, start at the empty prefix and test extensions with the next bit set to zero; keep a feasible extension and finally verify the decoded tuple. This takes at most $1+m(\ell+1)$ feasibility calls including a root check, with the same bound on every unsuccessful attempt. The verified success probability is at least $\Pr(U)(1-\epsilon)$ even if negative seeds have many false candidates. Each call needs an existence test over all completions of the pin. Testing just one completed address is cheaper and provides no such oracle. [Address encoding and retry budget](../sampled_slots/isolation.md)

## Which costs survive?

| Proposed saving | Result at the wrong-address threshold |
|---|---|
| Replace partial sums by independently hashed group labels | If each consumer can use any group value with the matching hash, a wrong tuple can pass by changing just one internal value. Every such link needs $b-o(b)$ bits to attain the required mean. The expected number of complete internal assignments has an exact convolution formula. [Proof](splices.md) |
| Use a short residue modulus in the integer chord equations | A small modulus can be certified for a product of narrow input intervals. At a balanced prefix, a prefix-aware dictionary of $2^{o(b)}$ possible integer product quotients covers the true quotient on at most $2^{-b/2+o(b)}$ of successful seeds under the stated information restriction. [Arithmetic tests](arithmetic.md) |
| Give each block a short, reusable message | Even allowing false candidates, the prefix-chain model needs $\Omega(mb)$ communicated bits and a balanced tree with the target at the root needs $\Omega(b\log m)$ under a large uniform mask. For a fixed target, a different bound prices descriptions when seeds stay local. [Cut bounds and assumptions](fingerprint.md) |
| Combine separately computed tags by addition | On prime-order groups under the full nonzero-target mask, complete additive tests into a group of coprime order accept a $1-O(1/m)$ fraction of legal addresses on average on regular singleton seeds. The proof allows each tag to depend on its local seed. [Rigidity proof](additive_tags.md) |

## Progress against the baseline

The preceding [masked-target predictor](../implicit_chords/projection.md) could meet an average error budget while missing the relevant bit on isolated seeds. The new filter has a one-sided guarantee on those seeds. It settles a statistical part of the problem and identifies one family of intermediate labels whose width cannot be reduced by ordinary independent hashing.

The project's best conditional upper bound on log expected time for the general-prime input class remains $(24.00245996+o(1))\,b/(\log_2 b)^{1/4}$. The original external paper gives the same asymptotic order with an unspecified leading constant. The project's earlier coefficient improvement is measured against the supplied intermediate manuscript under the shared comparison assumptions. This round changes neither numerical coefficient nor asymptotic order. The open step is a uniform computation of the filter's existence on pinned grids, or equivalent verified extraction, with the arithmetic, local degree and retries all within a smaller budget.
