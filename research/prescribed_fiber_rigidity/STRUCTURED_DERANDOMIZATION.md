# Coefficient rank after inserting the discrepancy

Take separate variable families for each slot of each of three short tuples. An ordered half-tuple \(X\) selects a distinct multilinear monomial \(M_X\). For field scores \(\sigma\) and a prescribed \(a\), give \(M_XM_YM_Z\) the coefficient \(\sigma(X)+\sigma(Y)+\sigma(Z)-a\) on the fiber of total \(t\), zero elsewhere. For target certificates the score is induced by a residual direction. Fixed reference offsets can be included in \(a\).

**Theorem.** At the cut \(X\mid Y,Z\), group rows by \(x=v(X)\) and columns by \(t-v(Y)-v(Z)\). Separate groups have disjoint supports. Inside one block the matrix has entries \(p_i+q_j-a\). It has rank two if both scores vary, rank zero if all entries vanish, and rank one in the remaining nonempty cases. For the rank-two claim take a two-by-two minor formed by unequal row and column scores. Its determinant is a product of two nonzero differences up to sign. Thus the rank of the whole matrix is the sum of these ranks. If \(\sigma\) is nonaffine and \(3s>2r+1\), it is at least \(3s-2r-1\) for **every** \(t,a\). Every mixed center in \(t-S\) gives a nonzero block.

This refines the repository's permutation-minor obstruction for the plain feasibility predicate. The discrepancy can erase some feasible entries, but enough entire coefficient blocks still survive. At Stage I density, width at least \(3s-2r-1>5r/8-1\) is necessary for a read-once oblivious algebraic branching program in any order that completes the first copy before reading the other two. A width \(w\) program at that cut expresses the polynomial as a sum of \(w\) left-right products. The coefficient-matrix rank bounds \(w\) from below. Since an any-order width bound must hold in particular in this order, bounded individual degree alone gives no affordable instance of the Shpilka theorem for this representation. A circuit with a different order may have smaller width. Substituting compact digit variables can lower the rank and may increase individual degrees. This calculation supplies no bound on the width after that substitution.

**Candidate-independent and candidate-dependent tests.** A list for a determinant must make one evaluation nonsingular, whereas a stack test requires only that every nonzero residual direction be detected somewhere. With a known affine target hyperplane one can instead test its scalar discrepancy polynomial. Monomials remain distinct before compact substitutions. Generic nonvanishing survives injective address encoding. Neither the sharp count of nonzero fiber classes nor this coefficient-rank calculation bounds a deterministic hitting list. Products of arbitrary point weights would reintroduce a lookup on \(\Theta(b/m)\) bits per slot. Small public geometric weights evaluated by digit splitting are a separate, justified interface.

Decoupling source and successor variables can expose a tensor cut; coupling them can identify coefficients. The PR #7 finite asymmetric lists establish no asymptotic hitting bound. Likewise a rank condenser on \(M\) implicit row coordinates requires an evaluation procedure charged in the relation model. Requiring \(h\) maps to \(k\) outputs to preserve **every line** already forces \(hk\ge M\) by the common-kernel argument. This is a universal black-box obstruction.
