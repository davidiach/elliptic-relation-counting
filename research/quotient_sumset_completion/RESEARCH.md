# Quotient-sumset completion and the limit of cardinality-only fiber probes

Research follow-up to PR #13 (head `bef28551c5fdd352cc3e641cd25e7b3f6ec08eb8`), PR #11 (`e833763d99b9e17e3c3544e0e01ad409bc111ed6`), PR #12 (`8a2ee0b78d1ea37e74a8d2ff700ed3bb819213f0`), and the merged main baseline `04a8b3d8bb904af8a30aa996f1af4027b52f6dd4`. 27 November 2026. The result is a new **restricted deterministic rank-completion criterion**, not the universal modular-rank lemma asked for in PR #13. Structural statements concern abstract prime-order groups. The bit-time applications assume the same closed LZR contraction premise as the current manuscript. The finite checks are synthetic mathematical instances only.

## 1. A different rank-completion operation

Let G be cyclic of prime order r with generator P. There are indexed blocks F_i and reference points R_i in them, with w_i positive occurrences per tuple. Write D=sum_i(|F_i|-1), and for a tuple X let c_X in F_r^D be its nonreference incidence vector. Put g_0=sum_i w_i R_i. Define the public linear map to the group

    pi(z) = sum_(i,A != R_i) [z_(i,A)](A-R_i).

The true scalar difference table lambda is defined by pi(z)=[z dot lambda]P, and is unknown. In particular pi(c_X)=val(X)-g_0. We use only ordinary group operations to evaluate pi, not the scalar table. The supplied explicit consistent modular equations are B lambda=b_B; all their right sides are known and independently checkable. Denote their row space by W. Assume at least one equation has nonzero RHS, so scale a known row to a with a dot lambda=1. Let U be the zero-value subspace of W. It is explicitly computable: take the span of B_j-(b_B)_j a. Since the right sides are consistent and a has RHS one, U=W intersect ker(pi), dim U=dim W-1.

Let H=F_r^D/U, h=dim H, and d=D-rank B=h-1. The quotient map pi_bar:H->G is well defined and onto. The projected short (or doubled) tuple support is the sumset

    S = {c_X+U : X is an allowed tuple}.

It has at most M=prod_i |F_i|^w_i elements. Suppose the tuple values cover G. For any z in H outside S, choose a lift x in F_r^D, evaluate the point g_0+pi(x), and find any allowed tuple X with that value. Then

    v = x-c_X,  pi(v)=0,  v+U=z-(c_X+U) != 0.

The row v with RHS zero is correct and is outside U. It is also outside W, because every zero-value row of W belongs to U. Thus **one missing quotient vector produces a genuine rank-increasing equation using just one ordinary group-value decomposition**. In particular it does not require finding two distinct scores in one previously selected fiber, a nonzero modular Gram entry, or a sparse independent fixed-generator row. The row is verified by group arithmetic and elimination before appending it. We are allowed to add such verified zero-value equations rather than requiring every new row to have bounded integer norm; no determinant bound on the augmented row set is used here.

This also explains exactly what a complete listed fiber can tell us about an arbitrary lift x: a rank increase is possible from this probe if some projected tuple at g_0+pi(x) differs from x+U. Being outside S is sufficient, not necessary. If every tuple in the listed fiber has the same projected value as x, this probe gives no progress. The source of the new equation is the deliberately chosen lift, not a hidden modular aggregate.

## 2. Deterministic small-projection and joint-support criteria

### 2.1 A single missing scalar

Let v be any explicitly given nonzero vector in U-perp (equivalently Bv=h_0 b_B for some h_0 in F_r). It need not annihilate the calibration row. For each block list

    C_i={0} union {v_(i,A): A in F_i, A != R_i}.

The possible tuple scores are C=sum_i w_i C_i, where w_i C_i denotes a w_i-fold Minkowski sum (not scalar multiplication of C_i). If t is any missing residue in F_r minus C, take one j with v_j!=0 and x=(t/v_j)e_j. A tuple with value g_0+pi(x) has score different from t. Thus x-c_X annihilates lambda but does not annihilate v, hence is not in U. This proves the preceding rank-increase lemma using only a **single-coordinate lift**, one scalar multiplication of a known point difference, and one ordinary decomposition. A nonzero v proportional to the true lambda cannot pass this test under full coverage, because its tuple scores already cover the whole field.

A capped exact sumset dynamic program finds a missing residue whenever |C|<=L_0<r. Begin at {0}, form successive sums with one C_i for each occurrence, store distinct residues, and abort as soon as the cap is exceeded. Since 0 belongs to every C_i, the intermediate supports are nested in the final support; thus an abort is sound and the successful branch never needs to visit more than L_0 distinct elements per intermediate set. Construct each next set by enumerating at most L_0|C_i| additions, stopping at L_0+1 different values. Sort the final set and find its first gap. This works with arbitrary residues, not just intervals or low-height lifts; there is no private arbitrary-label lookup in a contraction. In the absence of full coverage, a particular decomposition can fail; the deterministic theorem uses full coverage (e.g. the original doubled tuples).

There is a simpler interval branch when the labels admit integer lifts in each block of range R_i. If sum_i w_i R_i <= r-2, all tuple scores lie in a cyclic interval of that width, which omits a residue. The missing residue can be found without enumerating the support. Arbitrary per-block circular cuts are allowed (including the zero reference), and the interval's starting offset is the sum of its endpoints' lifts. In contrast to the corank-one short-lift result in PR #11, this gives rank progress at any corank, for any augmented annihilator with such a missing value. It requires full coverage with the indicated arity. At width r-1 this interval argument says nothing, so the inequality is deliberately strict enough to exclude that boundary.

### 2.2 One capped joint support suffices for full completion

There is a more useful all-directions version. Compute a basis u_1,...,u_d of the initial calibrated homogeneous kernel W-perp, so d is the residual modular dimension of the supplied equations. For each block define its projected column set

    C_i^joint = {0} union {(u_1,j,...,u_d,j) : j indexes a nonreference point in F_i}.

Compute by the same capped dynamic program the joint support J=sum_i w_i C_i^joint in F_r^d. **Theorem:** if |J|<=L_0<r, the supplied system is deterministically completable to full rank with at most d further ordinary decompositions. This condition is exact and checkable in polynomial time in the explicitly enumerated columns and L_0,b; the algorithm detects when the cap fails.

Proof. Maintain W' containing W and all newly verified rows. If its rank is not yet D, choose a nonzero vector v in (W')-perp. Express it as v=sum_j alpha_j u_j by field elimination. The possible tuple scores of v are precisely {alpha dot s:s in J}, a set of at most L_0<r residues. Pick a missing residue and use section 2.1, this time with v a homogeneous annihilator of the current equations. Its new zero-value row raises rank. The initial J is never recomputed. Repeat at most d times, at which point the consistent full-rank system gives the unique scalar difference table. An arbitrary target then uses an ordinary decomposition relative to a decomposition of identity, as in INTEGER_COMPLETION.md. No supposition that initial kernel basis vectors remain individual kernel vectors is made; using the joint support is what controls all subsequent linear combinations. QED.

One sufficient way to meet the cap is prod_i |C_i^joint|^w_i<=L_0. The actual dynamic program is often smaller than this product and does not assume that bound. The exact same argument works if a basis of the initial kernel has individually small scalar supports whose product is at most L_0, since joint support is bounded by that product. This latter sufficient condition is useful only with the actual product charged. Large corank is permitted if joint support is small; no fixed-dimensional assumption is needed. Alternatively test individual scalar directions and use a successful one to gain rank, but individual successes alone need not guarantee that a basis of subsequent kernel directions still has small support.

### 2.3 Costs on the original prime-order setting

Take the original LZR Stage I blocks at m=Theta((log b)^(1/4)) with doubled coverage (w_i=2), b=ceil(log2 p). Assume the closed contractor (LZR Theorem 2.2) and the inherited ordinary membership, group-arithmetic and exact prefix-counting compilation; include the time spent obtaining the supplied consistent B and the enumerated factor bases. If these fit 2^{O(b/m+mb/sqrt(log b))}, and L_0<=2^{O(b/m)} with L_0<r, all projection and joint-support tests above fit the same bound. Each stored element is a vector of at most D field elements, each of O(b) bits. Building the capped support lists uses O(L_0 sum_i w_i |F_i|) candidate vector sums and polynomial-time deterministic sorting or ordered-set operations; polynomial overhead in D,b,L_0 suffices on the stated bit model. The extra d<=D calls are ordinary doubled-tuple decompositions, each O(mb) prefix decisions on O(mb)-edge networks with the same degree and precision assumptions as MAIN_RESULT.md. Forming a single-coordinate lift and verifying its resulting equation costs polynomial time in D,b; even general dense elimination is polynomial. Space is bounded by time. Thus the **successful branch** is uniform deterministic at quarter-power time and space, without A.1 or the boundary-preserving expansion. There is no extra randomness or advice on that branch. A small quotient support for every actual extractor output is an unproved input-side condition.

The globally pointwise-enumerable short seed of PR #13 works with w_i=1 and its own slower seed exponent (any fixed delta<1/6); its full fiber enumeration is optional for this branch. On the faster prescribed-only seed of PR #13, (2) in that note controls the designated fibers, not all group points generated by this algorithm. Therefore use doubled coverage if established or another proved universal decomposition routine; do not transfer short coverage from prescribed points to arbitrary probes. This is an explicit coverage dependency, not an implicit ability to select arbitrary fibers of the targeted seed.

## 3. Strict complement to the earlier two sufficient conditions

We now exhibit an existential family in which both PR #11 conditions fail, even with the strong pointwise-flat/no-wrap numerical promises, but the missing-support branch succeeds. Like PRs #10 and #12 this is not the prescribed deterministic masks or their canonical extractor output, and the arbitrary augmented point sets do not come with a cheap membership circuit. It is a count-query example separating the mathematical conditions.

Take r odd prime tending to infinity, b=ceil(log2 r), m=Theta((log b)^gamma) for fixed gamma>0, K=2^floor(b/(64m)), delta=K^(-1/16), n=(Kr)^(1/m), D0=2^ceil(b/m). (D0 is the dictionary radix, not the number D of columns.) Choose a palette T of t=ceil(b^2) nonzero residues such that every nonzero dilation of T meets every cyclic interval of length at least floor(b^(-1/2)r). Such a palette exists: sample t independent uniform residues, discard the collision or zero events (probability O(t^2/r)), and union bound over at most r^2 relevant dilations and starting positions. A fixed interval is missed with probability at most exp(-Omega(b^(3/2))). Let C contain 0,1 and the residues used in ordinary binary addition chains for r and for every representative in T: at most O(b^3) residues. Record each operation x+y=z mod r in the chains, including the terminal operation for r. For these chains the exact integer prefixes before the terminal r are <r. Every member of C is generated from 1 using the recorded additions, with the terminal identity imposing r times the generator equal to zero in the quotient below.

### 3.1 Ordinary unweighted blocks and genuine basis

Use the two-coordinate dictionary idea from PR #12, but with the small palette replacing its full c-digit dictionary. In block i give points (c,t') the mathematical group value [1+tau t']P. Include

    d_(i,j) = (0,j D0^i), 0<=j<=D0;
    c_(i,a) = (a,a+zeta), a in C;
    special = (0,tau^(-1)).

Coordinates are modulo r. The reference is d_(i,0)=P. Choose nonzero zeta avoiding collisions between the c-values' second coordinates and d-digits in each block; at most O(m D0 |C|)=o(r) residues are excluded. Choose tau nonzero with neither tau^(-1) nor -tau^(-1) in the second coordinates of the d- and c-points (again O(m(D0+|C|))=o(r) exclusions). The special has value 2P. Each dictionary is unweighted, distinct and nonidentity within its block. Its size L_d=D0+2+|C|. Add further distinct nonidentity group points outside each dictionary; give each added point c-label in T and t'=(log_P A-1)/tau. The labels are only for the mathematical existence argument. One-per-block d-digits already cover all group values because D0^m>r.

Use reduced coordinates, u=(c_A), lambda=(tau t'_A). Let J_bad be the integer lattice generated by all genuine doubled-tuple unit-shift rows annihilating u modulo r. Its index is exactly r. Here is a direct proof. In the quotient, the class of every special point vanishes (a one-slot P->2P unit shift annihilates u). Whenever two padded doubled tuples have equal (c,t') sum and the first has a spare reference, replace that reference by the special to obtain a common successor. Subtract the two resulting genuine unit rows; this equates the two incidence classes. The comparisons below have such a spare reference (m>=2).

* The d-digit recursion d_j+P=d_(j-1)+d_1 and cross-block carries d_(i,D0)=d_(i+1,1) express all d-classes as integer multiples of one class e_d. Comparing the d-digit encoding of the integer r to the all-reference tuple gives r e_d=0. Comparing the special with the encoding of the nonzero representative of tau^(-1) gives tau^(-1)e_d=0, where the coefficient is the integer representative. Since r is prime, e_d=0.
* Compare c_(i,0) to the d-encoding of zeta. Its class is zero. Equal c-type points in different indexed blocks have equal classes via padded comparisons. For every recorded operation a+b=c in C, the two pairs (c_a,c_b) and (c_c,c_0) in one block have equal (c,t') sums, including when a+b=r. Their classes satisfy e_a+e_b=e_c. The addition chains give e_a=a e_1 and r e_1=0.
* For any added point (c,t') compare its singleton padded tuple with the tuple using one c-type point c_(0,c) and the d-digits of t'-c-zeta, one in each block, with references in the other slots. It has the same (c,t') sum and uses at most two occurrences in any block. Thus its class is c e_1.

Every coordinate class is generated by e_1, of order dividing r. The map z->z dot u modulo r kills the genuine unit rows and sends e_1 to 1. Hence the quotient has exactly order r and J_bad={z:z dot u=0 mod r}. The displayed proof uses O(D+m|C|+b|T|) ordinary bounded-norm rows. Choose D-1 modularly independent ones and extend by one rationally independent row. This is a full rational basis B with modular rank D-1, every RHS one. Its homogeneous kernel is span(u), and every augmented solution is h lambda+k u with h,k in F_r. As usual, full coverage implies full modular rank of the complete fixed-generator doubled-tuple family (compare tuples of the same value to a common successor, then advance around the generator cycle). The bad basis is only one possible selection; it is not the actual integer-prefix extractor's output on the actual masks.

### 3.2 Pointwise-flat augmentation

Retain each nonidentity point outside the dictionary independently with probability theta=(n-L_d)/(r-L_d-1). As in PR #10 and #12, L_d/n=2^(-Omega(b/m^2)), and the selected sizes are (1+o(1))n simultaneously with probability tending to one. For clarity the required modification of the earlier mixed deterministic/Bernoulli moment proof is the following. For any subset of s dictionary blocks (including identity if needed), the maximum convolution coefficient M_dict is 2^{O(m log b)}: fix the slots of each type and the O(b^3) palette choices in c-type slots, then the remaining integer d-digit sum is in [0,2D0^m], fixed modulo r by the group equation. There are 2^{O(m)} possible lifts, and at most 2^m digit choices per lift by peeling residues in [0,D0]. Thus the support size is between L_d^s/M_dict and L_d^s. The palette has only added a factor polynomial in b per slot compared to PR #12.

For a mixed term with k random slots and a deterministic convolution w of support size s_0 and coefficient bound M_dict, use q'=r theta, mu=(q')^k s_0/r. The raw and centered moment bounds in PR #10, section 4.2, are respectively

    E Z^H <= M_dict^H Bell(H)^k max(1,mu)^H,
    E (Z-E Z)^H <= 2^H M_dict^H Bell(H)^k mu^H K_*^(-H/4)

for even H, the second when q',mu>=K_*>=1. The proof counts tuple-equality partitions, then excludes isolated centered tuples. In each partition with ell classes and rank R of the class-incidence matrix, there are at most s_0^R r^(ell-R) point assignments with nonzero weight and their retention probability is theta^ell; ell<=kR. Centering contributes at most 2^H theta^ell and, for a nonisolated pattern, either H-R>=H/4 or kR-ell>=H/4, by the same support-of-transpose-kernel merger inequality. This is exactly the weighted moment estimate from PR #10, with only M_dict changed.

Uniformly mu=2^{+-O(m log b)} K^(k/m). Take H=8192m, T_0=K delta/2^(m+2). All extra M_dict^H and Bell and combinatorial factors are 2^{O(m^2 log b)}=2^{o(b)}. For k>=m/2, use K_*=K^(1/3) in the centered bound: the probability of deviation exceeding T_0 is at most 2^{o(b)}K^(-H/48)=2^{-8b/3+o(b)}. For 0<k<m/2, the mean is at most M_dict mu=o(T_0) and the raw moment gives 2^{o(b)}K^(-7H/16) as an upper bound on the probability of exceeding T_0/2. The all-dictionary term is deterministic. Union over all r targets and 2^m mixed terms is permissible. The mean count differs from K by at most M_dict+(L_d+1)^m/r=2^{O(m log b)}=o(K delta), by expanding each expected block indicator as theta 1_G plus its dictionary/identity correction (every convolution containing 1_G is constant). Summing the mixed deviations gives |d(g)-K|<=K delta simultaneously. Finally W0=prod |F_i|<=rK(1+delta), so the one-sided one-pin short-pair count is positive and at most r K^2(1+delta)^2/L_d<r eventually. This verifies the claimed no-wrap promise. These are existence estimates for the same ordinary unweighted block model, not a new affordable deterministic construction.

### 3.3 Neither PR #11 condition holds, but the new one does

Conditional on the retained group points, give each added point an independent uniform label from T. For k!=0 the residues h lambda_A+k u_A, for any h, have a probability at least 1/|T| of lying outside any cyclic interval of width (1-2b^(-1/2))r: the complement contains an interval of the required length, and translating it by h lambda_A and dilating by k preserves the palette hitting property. There are at least n/2 newly retained points per block with probability tending to one. Thus the probability that all lie in a specified such interval is at most (1-1/|T|)^(n/2). Union bound over m blocks, r^2 pairs (h,k) and r starting positions. For k=0,h!=0 the retained group points themselves are a uniformly sampled subset of a complement of o(r b^(-1/2)) forbidden points, conditional on their number; the analogous probability is exp(-Omega(n b^(-1/2))), again sufficient. These events may be intersected with the pointwise-flatness event, because their failure probabilities tend to zero. Every nonzero augmented solution consequently has circular range at least (1-o(1))r in every block, ruling out the short-lift criterion even after arbitrary cuts. If the modular solution is zero, a nonzero integer lift with zero references has some nonzero multiple of r and range at least r.

For each added-label class the expected size is at most 2n/|T| conditional on the sizes being <=2n; ordinary binomial concentration and union over the polynomial palette and m blocks show the maximum relative size is O(1/|T|). The dictionary contributes at most L_d/n=o(1). Thus the largest quotient-class fraction tends to zero in every block. No nonempty subset passes a fixed positive joint modal-fraction condition of PR #11. In this corank-one example quotient classes are exactly equality of c-labels.

**Nevertheless, every score of u on a one- or two-copy tuple belongs to a sumset of at most |C|^(2m)=2^{O(m log b)}=2^{o(b/m)} residues.** In particular its score support is smaller than r and within the desired cap. Since the homogeneous kernel is one-dimensional, elimination recovers a nonzero multiple of u without knowing the constructed labels, and the support test on that multiple has the same cardinality. Section 2 finds a missing score and gives one verified zero-value row, recovering full rank. Even when circular width is almost r, the *number of attainable scores* may be extremely small. This is the distinction from the short-lift and modal-product tests. The example admits a constructive count-query resolution, not a cheap circuit for membership in these arbitrary augmented blocks. The general actual-mask quarter-power branch is justified separately in section 2.

## 4. Scope limit: surjective projections and cardinality-only probing

### 4.1 Why the earlier counterexample is not covered by the new test

The actual PR #12 dictionary uses two full radix digit types. Its d-type points alone give every group-difference scalar and zero homogeneous score. Its c-type points alone give every homogeneous score. For any nonzero augmented solution h lambda+k u, if h!=0 the d-type encodings cover F_r, and if h=0 use the c-type encodings. Thus *every* nonzero augmented scalar projection of the short tuple support is already surjective on this family. This verifies that the missing-scalar criterion, even extended to all augmented solutions and arbitrary cuts, cannot follow from pointwise-flatness/no-wrap and full rational rank alone. In the doubled-tuple architecture the joint quotient itself is covered, as proved in PR #12. The new positive result therefore complements rather than replaces PR #13's actual identity-fiber repair of that example.

### 4.2 A quantified barrier to using only fiber sizes in a fixed plane

For the globally pointwise seed short tuples have total cardinality M=r^(1+o(1))<r^2. When the quotient H has dimension at least two, any fixed two-dimensional subspace L contains r^2 points, of which at most M are tuple projections. Uniform random z in L is outside S with probability >=1-M/r^2. One group decomposition gives rank progress by section 1. If L contains the calibrated a and short coverage is only the original dense Stage I promise, pi_bar(z) is uniform and the additional failure probability is at most the uncovered density. This is a randomized alternative observation, not an improved end-to-end random-bit theorem: if repeated at each rank step, the trials must be charged at each step. The existing polynomial certificate already gives O(b) expected random bits for the full algorithm.

For a deterministic fixed probe list one cannot infer success solely from a bound on the number of quotient values in each group fiber. Here is an exact finite-geometry bound. Let L be an abstract affine plane F_r^2, let E be a set of probe points, and suppose an unknown nonzero linear map L->F_r has fibers that are parallel lines. A possible support has at most K_0 points on each such line, 1<=K_0<r. A guarantee that E contains a missing point for every such support and every direction requires that for every direction some line contain at least K_0+1 points of E: otherwise the possible support can include E itself (and can be extended to nonempty fibers if desired). In each direction that property accounts for at least binom(K_0+1,2) distinct unordered pairs in E. Each pair contributes to exactly one of the r+1 line directions. Hence

    |E|(|E|-1) >= (r+1) K_0(K_0+1).

In particular even K_0=1 requires Omega(sqrt(r)) probes in this direction-oblivious, cardinality-only guarantee. This is NOT a lower bound for adaptive point selection, for supports known to be the structured Minkowski sums of the actual factor-base labels, for the real group arithmetic, or for ECDLP. It is a precise limitation on an otherwise tempting shortcut from the small-fiber theorem. The new missing-support test uses more than cardinality information, namely the explicit additive decomposition of the quotient support.

## 5. Verification and success assessment

Run `python -B check_quotient.py /path/to/PR12/research/dual_lift_obstruction/check_dual_lift.py`. NumPy and SymPy are needed. Omitting the argument skips the three inherited-dictionary controls. The synthetic finite tests verify every selected unit-shift relation, exact modular rank and rational rank (the latter certified by independent full modular rank at a different prime), exact Smith forms for the two smaller selected row families, an exhaustive search of all nonzero augmented modular coefficient pairs with independent circular cuts, and the capped Minkowski sums. The verifier explicitly selects a square rational basis preserving modular rank, computes the homogeneous kernel from that basis, obtains a missing value, and verifies the new zero-value equation before solving the complete linear system. No hidden scalar table is used to choose the missing score; scalar coordinates in the tests serve only to model ordinary group operations and check ground truth. No asymptotic tensor-contraction implementation is claimed. The no-wrap finite order-2039 control has rational rank 206, modular rank 205, a 331-element one-copy score support and an 1895-element doubled score support, both strictly smaller than r; all one-pin masses are in [355,1700]. Both modes recover full rank with one additional verified row. On three higher-corank fixtures the joint-support procedure recovers all missing dimensions using exactly d rows. Two smaller examples have surjective doubled score support, and the method correctly reports failure on that branch. All three PR #12 controls have surjective short scalar projections. The finite palettes are not examples of the asymptotic vanishing modal fractions; those are proved by the existence argument in section 3.

The complete prescription from PR #13 is **still unresolved**. The strongest new positive statement is an affordable deterministic rank completion from any supplied genuine system with capped joint quotient support, or an adaptive sequence of missing scalar certificates. It covers examples that the two earlier criteria miss, and does not rely on modular noncancellation. The relevant remaining task is to construct an affordable deterministic missing-quotient probe or prove the actual extractor produces a residual system amenable to a sufficient criterion, including direct enumerable-fiber tests. Small fiber sizes alone do not prove either. A generic randomized two-plane search, or a generic density argument, does not meet the requested zero-random-bit criterion.

No new positive end-to-end deterministic saving exponent, independent proof-chain audit, or literature-priority claim is made. Classical ingredients used here include quotient linear algebra, finite sumsets, addition chains, elementary union bounds and counting line directions. The PR #10 mixed moment proof is inherited rather than claimed anew. Source assurance for the closed contractor remains outstanding. The positive result uses no new computational assumption beyond the closed premise, but the checkable small-support condition is additional. The mandatory breakthrough checklist fails.
